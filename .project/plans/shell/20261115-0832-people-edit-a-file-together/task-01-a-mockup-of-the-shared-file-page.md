## Objective

Softov approves a mockup of the shared file page before the build.

## Files

- `CREATE: .scratch/mockups/shared-file.html` - the page in each state, at two widths, in both themes.

## Steps

1. Copy the file page's current markup and styles from the running app.
2. Draw the locked page: the people in the header, their carets with name tags, and the Edit button.
3. Draw the page after Edit in Live save: the save mode picker, and "Saved" or "Saving".
4. Draw the page in Manual save with edits not sent, and the Save button.
5. Draw the `ui.fileSaveMode` setting in the settings window.
6. Show each state at 1280 and 760 wide, in light and dark.
7. Take screenshots and send them to Softov.
8. Record his approval as a row in the plan's *Answers*.

## Validation

- Softov approves the mockup.
